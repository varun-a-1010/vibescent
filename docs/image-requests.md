Save each image as an 800 by 800 JPEG under 150 KB in `public/samples/`, using the exact filename.
A look already works without its photo, and picks up the file once it is deployed. The photo is sent
to Gemini as part of the look, so the clothing has to be clear.

Style for all six: a realistic, editorial fashion photo, cropped from the neck down so no face is
visible, in natural light. No logos, team marks, brand names or readable text.
